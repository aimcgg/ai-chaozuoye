# AI摩擦哥的抄作业包

看了我的视频想照着做？每期视频用到的提示词、步骤、模板都在这里，免费复制。

## 怎么用

1. 在下面的「每期目录」里找到你看的那期，点进去。
2. 那期页面里有灰色的代码框，右上角有个复制按钮，点一下就复制好了，粘到豆包、DeepSeek 这类 AI 里用。
3. 想把整期文件存到电脑：回到这一页，点绿色的「Code」按钮，再点「Download ZIP」。

不用注册，不用登录。觉得有用，点右上角的 ⭐ Star，下次好找。
