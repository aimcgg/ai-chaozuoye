## 这里有什么

每期一个文件夹，里面有：

- **步骤**：一步一个动作，不看视频也能照着做
- **提示词**：复制过去就能用
- **模板**：表格、配置文件，下载就能用

全部免费。

## 第一次用 GitHub？看这里

1. 在下面的目录里找到你看的那期，点进去。
2. 看到灰色的代码框，右上角有个复制按钮，点一下就复制好了。
3. 想把整期文件下载到电脑：回到首页，点绿色的「Code」按钮 → 「Download ZIP」。

不用注册，不用登录。
